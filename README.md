# ДУМ: АЛЬТУШКИ 💘

Браузерный шутер в стиле Doom: альтушки наступают волнами, герой отстреливается сердечками.

**Играть:** открой `index.html` в браузере — или по ссылке на GitHub Pages.

## Особенности

- Псевдо-3D raycasting-движок (как Wolfenstein 3D) на чистом JS + Canvas, без зависимостей — всё в одном файле
- 3 уровня-лабиринта 28×28 в духе классического Doom: комнаты, коридоры, развилки и тупики с предметами
- Три вида рядовых альтушек: обычная (быстрая, в мили), толстушка-обнимашка (медленная, но дойдя — обнимает: стан и взрыв сердечками с большим уроном) и кричащая готка (дальний бой: стонущий крик летит в тебя видимой звуковой волной, зато здоровья у неё меньше)
- Альтушки слышат выстрелы (даже за стеной), агрятся от попаданий, а пока тебя не заметили — бродят по лабиринту
- Волны врагов и в конце каждого уровня — уникальный босс (Бариста Люба, Настя Шипастая, Королева Альтушек)
- Боссы стреляют летящими поцелуями — уворачивайся стрейфом или прыжком; Настя и Королева периодически кастуют АОЕ-зону прямо по твоей позиции (и бьют волной вблизи), а Королева вдобавок телепортируется
- Вертикальность: приподнятые платформы, за которыми можно прятаться (и враги за ними тоже прячутся); вишнёвая вода замедляет и тебя, и врагов
- Оружие: сердечки (∞), ракетница с мега-сердечками (взрыв по площади) и лазерган с прошивающим розовым лучом (со 2-го уровня)
- Предметы: аптечки, броня, ракетница и лазер — часть наград спрятана на высоких платформах
- Вся графика и звук генерируются кодом: спрайты, текстуры, floor casting, WebAudio
- Тихая фоновая музыка в духе готик-рока (процедурный секвенсор с эхом) и три случайных стона очарованных альтушек

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ← → | поворот |
| ЛКМ | стрелять |
| Пробел | прыжок (в прыжке поцелуи пролетают мимо, и можно запрыгнуть на платформу) |
| 1 / 2 / 3 | смена оружия (сердечки / мега / лазер) |
| P / Esc | пауза |
