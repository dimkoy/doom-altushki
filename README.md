# ДУМ: АЛЬТУШКИ 💘

Браузерный шутер в стиле Doom: альтушки наступают волнами, герой отстреливается сердечками.

**Играть:** открой `index.html` в браузере — или по ссылке на GitHub Pages.

## Особенности

- Псевдо-3D raycasting-движок (как Wolfenstein 3D) на чистом JS + Canvas, без зависимостей — всё в одном файле
- 3 уровня, волны врагов и в конце каждого — уникальный босс (Бариста Люба, Настя Шипастая, Королева Альтушек)
- Боссы стреляют летящими поцелуями — уворачивайся стрейфом или прыжком
- Вертикальность: приподнятые платформы, на которые нужно запрыгивать; вода замедляет и тебя, и врагов
- Оружие: сердечки (∞), ракетница с мега-сердечками (взрыв по площади) и лазерган с прошивающим розовым лучом (со 2-го уровня)
- Предметы: аптечки, броня, ракетница и лазер — часть наград спрятана на высоких платформах
- Вся графика и звук генерируются кодом: спрайты, текстуры, floor casting, WebAudio

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ← → | поворот |
| ЛКМ | стрелять |
| Пробел | прыжок (в прыжке поцелуи пролетают мимо, и можно запрыгнуть на платформу) |
| 1 / 2 / 3 | смена оружия (сердечки / мега / лазер) |
| P / Esc | пауза |
