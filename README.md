# ДУМ: АЛЬТУШКИ 💘

Браузерный шутер в стиле Doom: альтушки наступают волнами, герой отстреливается сердечками.

**Играть:** открой `index.html` в браузере — или по ссылке на GitHub Pages.

## Особенности

- Псевдо-3D raycasting-движок (как Wolfenstein 3D) на чистом JS + Canvas, без зависимостей — всё в одном файле
- 3 уровня, волны врагов и босс в конце каждого уровня
- Босс стреляет летящими поцелуями — уворачивайся стрейфом или прыжком
- Предметы: аптечки, броня и ракетница с мега-сердечками (взрыв по площади)
- Вся графика и звук генерируются кодом: спрайты, текстуры, WebAudio

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ← → | поворот |
| ЛКМ | стрелять |
| Пробел | прыжок (в прыжке поцелуи пролетают мимо!) |
| 1 / 2 | смена оружия |
| P / Esc | пауза |
